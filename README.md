# Supplementary Material: PPG features correlated with BP changes

The supplementary materials in this folder include detailed original code for statistical analysis, feature selection, model building, and plotting in the study: "Blood Pressure-Related Differences in Finger Photoplethysmography Signals", October, 2026. The code operates on Python 3.14, shap 0.52.0, scikit-learn 1.9.0, statsmodels 0.15.0, and pandas 3.0.5.

## Folder Structure

```text
Supplementary_Material_PPG_features_correlated_with_BP_changes/
├── ana_*.py (8 Analysis Scripts)
├── plot_*.py (6 Plotting Scripts)
├── output_data_used/ (Output datasets & results)
└── figure_used/ (Generated figures)
```

## Python Scripts

To be specific:

1. **ana_1_statistical_analysis_BP_difference.py**: 
Perform statistical analysis on blood pressure (BP) differences across different postures.

2. **ana_2_heart_cuff_finger_height.py**: 
Based on anthropometric proportions and the hydrostatic effect, calculate the vertical heights between the heart and the cuff, the heart and the finger, and the cuff and the finger, as well as the theoretical hydrostatic pressure variations from the heart to the finger and reference BP recordings.

3. **ana_3_ppg_vpg_apg_fiducial_point_extraction_rate.py**: 
Calculate detection rate of PPG, VPG, and APG fiducial points.

4. **ana_4_SHAP_analysis_contribution.py**: 
Conduct SHAP (SHapley Additive exPlanations) analysis to evaluate the contribution of each PPG feature.

5. **ana_5_two_stage_feature_selection.py**: 
Implement the two-stage feature selection process to identify the most relevant features for SBP, DBP, and MAP.

6. **ana_6_regression_decision_tree_model_build.py**: 
Build and evaluate the regression decision tree models using the selected PPG features.

7. **ana_7_Feature_similarity_across_SBP_DBP_MAP.py**: 
Analyze the similarity and overlap of significant PPG features across SBP, DBP, and MAP.

8. **ana_8_subgroup_analysis_healthy_and_older_cohort.py**: 
Subgroup analysis comparing age, baseline SBP, baseline DBP, baseline perfusion index, top-three selected features, and feature contribution consistency across overall, healthy young and older hypertensive cohort.

9. **plot_1 to plot_6 scripts**: 
Six plotting scripts (`plot_1_histogram...` to `plot_6_barchart_heatmap...`) used to generate the respective manuscript figures (Figure 1, 3, 5, 6, 7, and 8).

## Output Data (`output_data/`)

This folder contains intermediate and final data results generated by the analysis scripts:

* **SHAP Analysis Files** (`1_SBP_...txt`, `2_DBP_...txt`, `3_MAP_...txt`): Detailed SHAP value calculations for the 161 extracted features.
* **Feature Selection Results** (`*stage1_screened_features.csv`, `*stage2_clusters_features.csv`): Selected and clustered features after Stage 1 and Stage 2 for SBP, DBP, and MAP.
* **a_posture_hydrostatic_vertical_height.xlsx**: Vertical height variations, theoretical hydrostatic offsets, and measured BP across five postures and details for each subject.
* **a_posture_statistical_analysis.csv**: Statistical results evaluating the effect of posture changes.
* **b_ppg_point_detection_rate.xlsx**: Detection rate of fiducial points from PPG, VPG and APG.
* **c_stage2_overlapping_features_summary.csv**: A summary of overlapping features across different BP metrics in Stage 2.
* **d_independent_validation_5fold_cv_*.csv**: Metrics and prediction results from the 5-fold cross-validation.
* **e_subgroup_analysis.xlsx**: Subgroup analysis results among the overall, healthy young and older hypertensive cohort.
