=================================================================================================================================================
METHOD SUMMARY
=================================================================================================================================================
1) 70 subjects are divided into 5 subject-level folds using a fixed random seed.
2) For every subject, four delta morphological samples are generated from rows 1-4 minus baseline row 0.
3) Five subject-level demographic variables are taken from the baseline row, ordered as s1=Gender, s2=Age, s3=Height, s4=Weight, s5=BMI, and repeated four times.
4) The 156 delta morphological features and the five repeated demographic features are horizontally concatenated into a 161-dimensional input vector.
5) Each fold trains Random Forest on 56 subjects and evaluates prediction performance on 14 completely unseen subjects.
6) SHAP feature importance is calculated on the 56-subject training data using TreeSHAP.
7) Final contribution is the mean of the five fold-wise mean(|SHAP|) values.
8) For MAP, MAP = 1/3*SBP + 2/3*DBP is calculated row-wise first, and then ΔMAP = MAP[1:5] - MAP[0].
9) Subject-level separation is preserved so that all four samples from a subject are always assigned to the same fold.
10) SHAP values quantify model contribution and should not be interpreted as causal physiological effects.
=================================================================================================================================================
